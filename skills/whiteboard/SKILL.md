---
name: whiteboard
description: Interview the user relentlessly about a plan or design until reaching shared understanding, resolving each branch of the decision tree. Use when user wants to design important, system-wide architecture, have a deep dive discussion, or mentions "whiteboard".
---

Interview me relentlessly about every aspect of this plan until we reach a shared understanding. Walk down each branch of the design tree, resolving dependencies between decisions one-by-one. For each question, provide your recommended answer.

Ask the questions one at a time.

If you find yourself going around in circles debating an implementation, ask the user instead - they may have a better understanding of the problem space than you do. If the user is unsure, ask them to explain their thinking and reasoning behind their uncertainty.

If a question can be answered by exploring the codebase, explore the codebase instead.

Once you are fully done questioning the user, ask if they'd like to:

1. Implement the plan
2. Create a PRD using the write-a-prd skill (if available)
3. Do nothing for now
